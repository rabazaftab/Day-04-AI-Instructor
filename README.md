# 👨‍🏫 AI Instructor

AI-powered educational assistant that explains concepts, answers questions and helps users learn different subjects.

## 🚀 Features

- Ask questions about different topics
- AI-powered explanations
- Beginner-friendly responses
- Interactive learning experience
- User-friendly web interface
- FastAPI backend
- HTML, CSS and JavaScript frontend
- OpenRouter API integration

## 🛠️ Tech Stack

- Python 3.14
- FastAPI
- HTML
- CSS
- JavaScript
- OpenRouter API
- LLM
